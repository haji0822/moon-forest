# 달이 잠든 숲 (THE FOREST WHERE THE MOON SLEEPS)

두 사람을 위한 방치형 다크 판타지 웹게임. HTML/CSS/Vanilla JS + Firebase.

## 현재 상태: 1단계 완료 (기반)

### 구현됨
- 로그인 / 로그아웃 / 로그인 상태 유지 (이메일+비밀번호). 게임 화면에서 가입하되 초대 코드와 정원 2명으로 제한
- 초대 코드·정원(2명)·멤버만 읽고 쓰는 Firestore 보안 규칙
- 접근 거부 화면 (내 UID 표시)
- 플레이어 문서 저장·불러오기, 표시 이름 수정 (저장 후 재조회로 확인)
- 반응형 레이아웃 (PC 사이드바 / 모바일 하단 메뉴), 디자인 변수
- Firebase 설정 누락 시 안내 화면

### 미구현 (메뉴에 "개발 예정"으로 비활성 표시)
캐릭터·세계 시간·날씨(2단계), 탐색·생존(3단계), 육성·소지품(4단계), 이벤트·쪽지·시설(5단계)

## 시작하기
`FIREBASE_SETUP.md`를 따라 하세요.

## 폴더
- `js/firebase-config.js` : 직접 수정하는 유일한 설정 파일
- `firestore.rules` : 보안 규칙 (콘솔에 붙여넣기)
- `js/pages.js` : 화면 그리기 (요청서 구조에 추가한 파일)
- `data/` : 2단계부터 채워질 게임 데이터

## 보안 참고
웹 설정값은 공개되어도 되며, 데이터 보호는 보안 규칙이 합니다.
서버 없이는 게임 결과 계산을 브라우저가 하므로, 규칙으로는 UID·필드·값 범위만 검증할 수 있습니다. 두 사람만 쓰는 비공개 게임 기준의 설계이며, 더 강한 보호가 필요하면 Cloud Functions로 확장합니다.
